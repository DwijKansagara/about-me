About

Curious about the point where software becomes an experience.

I am Dwij Kansagara, a 10th-standard student developer from Rajkot, Gujarat. I work across front-end engineering, browser-based machine learning, voice interfaces and physical computing.

I like projects that make technical ideas tangible: a camera model that responds in the browser, a voice assistant that runs as a real interface, or a scroll narrative that turns code into atmosphere. I care about understandable controls, honest project descriptions and details that reward attention.
